# Ki Integrated Attendance System (Ki-ATTEND)

**Developer & Architect:** ki  
**Copyright:** © 2026 ki. All Rights Reserved.  
**Target:** كلية التقنيات الصحية والطبية - قسم تقنيات التخدير (المرحلة الثانية)  

## وصف المشروع
نظام غيابات ذكي ومحترف يعتمد على نظام القيم الثنائية (1 للحضور، 0 للغياب) لكل أسبوع (8 أسابيع)، مع دعم كامل للمحاضرات النظرية (نظام المرحلة كاملة باللون البرتقالي) والمحاضرات العملية (مقسّمة إلى Group 1 و Group 2 باللون الأصفر) بناءً على الجداول الأكاديمية الرسمية.

## المميزات الرئيسية
* إدارة سجلات 181 طالباً وطالبة بدقة مع الكودات الجامعية.
* محرك اتخاذ القرار التلقائي (منتظم، تنبيه أول، إنذار نهائي، محروم).
* واجهة تفاعلية حديثة ومتجاوبة.
